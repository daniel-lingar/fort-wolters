Class & roster evidence

The object is marked Class 65-9WA. The external VHPA photograph identifies the related Fort Wolters class as 65-9W, and the handwritten roster is marked CLASS 65-9 R/W. This packet presents that naming difference openly so the auction house can determine the best catalog wording.

The VHPA roster is useful support because the surname Lancy appears in the top row of the roster and the same name appears on the engraved presentation lighter.

Class designation in external sources: 65-9W / 65-9 R/W
Class designation on object: 65-9WA
Year: 1965
Location: Fort Wolters, Texas
Aircraft named in inscription: Hughes TH-55A helicopter

Aircraft significance

The Hughes TH-55A Osage was used as a primary helicopter trainer at Fort Wolters during the period named in the inscription. The lighter is submitted for auction-house review because the period engraving directly connects the object to the training transition named on the piece.

Later service context

This newspaper page lists WO Arthur P. Lancy, Co. B, 25th Avn. Bn. under the Air Medal section. It documents later service context only and does not prove the lighter was carried in Vietnam, used in combat, or tied to a specific aircraft type beyond the training helicopter named in the inscription.
